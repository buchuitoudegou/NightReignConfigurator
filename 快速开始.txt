Nightreign Configurator 便携版

1. 完整解压到可写目录，不要放进游戏目录。
2. 双击“一键配置.cmd”。首次需要联网，从官方 GitHub 下载约 392 MiB 的依赖，解压后需要更多磁盘空间。无需安装系统版 PowerShell、ME3 或 Smithbox。
3. 配置向导自动查找 Steam 游戏和无缝 DLL。核对路径，点击“验证并保存”。找不到无缝时，先安装无缝联机；本包不下载或修改无缝密码。
4. 选择夜王、永夜、地形和 Map pattern，点击“确定并生成”，然后关闭配置器。
5. 先登录 Steam，再双击“启动游戏.cmd”。它通过 ME3 加载最近一次生成的 regulation.bin，游戏目录原始文件不被替换。
6. 如启用了固定 Map，启动时会同时打开房主锁定器。进入圆桌厅后，在锁定器点击“应用房主锁定”，保持窗口开启。不要以访客身份应用。多人地图同步仍属待验证功能。

修改选择：直接双击 Nightreign-Configurator.exe，生成后重新启动游戏。
修改安装路径：重新运行“一键配置.cmd”。移动整个程序文件夹后也需要重新配置并生成。
错误提示：启动失败时 CMD 会保留报错，不会一闪而过。
运行数据：保存在 data；依赖保存在 vendor。不要将使用后的整个目录上传到 GitHub。

支持 Windows x64。当前只接受已验证的游戏 1.03.5 参数，房主锁定还要求匹配的 EXE；不承诺兼容其他版本。
首次配置及游戏进程启动仍需在目标电脑验收。见 README.md 与 THIRD_PARTY.md。
